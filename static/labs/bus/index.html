Bus animation tests

Entries for the little bus, on the real production stylesheet. Each one overrides only the motion variables the live CSS already exposes, so picking a winner means copying numbers into ngbus.css — no new code. Try them on a phone as well as a laptop; the note that the arrival is too small came mostly from big screens.

The bus stop is a stand-in — drawn here to test whether the idea works, not to be shipped. If a stop variant wins, the real one comes from the same Claude Design session as the buses, in the same palette and line weight, and the chosen entrance moves into production with it.

All Each card replays on its own too.

1. How the bus arrives

The thing your testers were reacting to: today the bus travels 7% of its own width inside a box that never clips it, so there is nothing for it to arrive from. Everything below adds a clipping stage.

2. How the stop appears

Four entrances were tried here — the stop planting itself before the bus, the sign popping on as the bus landed, the pole drawing up and the sign dropping onto it. All rejected on 28 Aug in favour of a stop that is simply already standing there. Street furniture that assembles itself in front of you is a joke that works once, and these pages are meant to be revisited. Removed rather than left here to rot; the CSS is in the git history if it is ever wanted again.
