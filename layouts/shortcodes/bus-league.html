PROGRESSIVE ENHANCEMENT, the same bargain the rail chart strikes --------------------------------------------------------------- The worst `rows` routes are rendered here as real HTML, sparklines and all. {{- /* jsonify escapes < > &, so the payload cannot close this tag. safeJS stops Go's contextual escaper from re-encoding the JSON as a JS string, which would leave JSON.parse() parsing a string. Same trick as ng-chart2.html. One dict per route with one-letter keys. The obvious compaction — positional arrays — is not available: Hugo's `append` spreads a slice argument into its elements, so appending a row flattens all 616 of them into one long list of scalars, and wrapping the row to stop that makes the outer value a [][]interface{} which cannot be appended to a []interface{} at all. Short keys cost about 12 KB across the whole table and cannot be got wrong. */ -}} {{- $payload := slice -}} {{- range $all -}} {{- $where := "" -}} {{- with .termini }}{{ $where = delimit (apply .
