{{- /* bus-spark — a sparkline of weekly EWT, rendered server-side. Server-side because the league table's first twenty rows are real HTML: a reader with JavaScript off, or a crawler, gets the trend as well as the numbers. `ngbus-table.js` draws the identical shape for rows it adds later — same geometry constants, so a sorted table does not visibly re-draw. Drawn as one per adjacent pair rather than as a polyline, which makes gaps fall out for free: a pair with a missing end simply has no line. Missing weeks are then shaded, so a gap reads as "not measured" rather than as a straight line drawn through the outage — which is exactly the lie the whole page exists to avoid. Coordinates are printed to 2dp. Full float64 precision costs ~17 characters per number and twenty sparklines' worth of it is several KB of page weight that no one can see. Params: values (slice, nulls allowed), lo, hi (domain), label */ -}} {{- $v := .values -}} {{- $n := len $v -}} {{- $lo := .lo -}} {{- $hi := .hi -}} {{- $span := sub $hi $lo -}} {{- if le $span 0.0 }}{{ $span = 1.0 }}{{ end -}} {{- $W := 78.0 }}{{ $H := 22.0 }}{{ $pad := 2.0 -}} {{- $step := cond (gt $n 1) (div (sub $W (mul $pad 2)) (float (sub $n 1))) 0.0 -}}
